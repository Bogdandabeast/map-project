# 🗺️ Bienvenidos al Map Project

Si estás leyendo esto, es porque te sumás al equipo como becario. Bienvenido.

Acá no buscamos "picacodigos". Buscamos ingenieros. No nos importa que sepas usar un framework de memoria; nos importa que entiendas **cómo funciona el software**.

## 🎯 Nuestra Visión
Construimos una plataforma de mapeo donde la **consistencia de los datos** y la **predictibilidad de la interfaz** son la prioridad absoluta. Queremos un sistema donde el estado sea determinista y el comportamiento sea predecible.

## 🧠 El Mindset del Equipo
Para sobrevivir y crecer acá, tenés que adoptar estos tres pilares:

1. **TDD (Test Driven Development)**: No escribimos código y luego tests. Escribimos el test, vemos que falle, y luego escribimos la mínima cantidad de código para que pase. Si no hay test, el código no existe.
2. **Tipado Estricto**: TypeScript no es una sugerencia, es nuestra ley. El uso de `any` es una señal de que no entendés el problema. Si el compilador grita, es porque te está salvando de un bug en producción.
3. **Determinismo (FSM)**: Odiamos los "glitches" y los estados inconsistentes. Por eso usamos Máquinas de Estados Finitos (FSM). La UI es un reflejo exacto de un estado finito y bien definido.
